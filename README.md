# Console 2048

콘솔 기반 2048 게임 (F# / .NET 10)

## 게임 방법

시작 시 난이도를 선택하면 4×4 보드에서 게임이 시작됩니다.  
같은 숫자 타일을 밀어 합쳐 목표 타일에 도달하면 승리합니다.

| 키 | 방향 |
|---|---|
| `W` / `↑` | 위 |
| `S` / `↓` | 아래 |
| `A` / `←` | 왼쪽 |
| `D` / `→` | 오른쪽 |

## 난이도

| 난이도 | 입력 | 목표 타일 |
|---|---|---|
| Easy   | `1` | 256  |
| Medium | `2` | 1024 |
| Hard   | `3` | 2048 |

## 규칙

- 이동 시 모든 타일이 선택한 방향으로 최대한 밀립니다.
- 같은 값의 타일이 충돌하면 두 배 값으로 합쳐지며 점수에 합산됩니다.
- 한 번의 이동에서 각 타일은 한 번만 합쳐집니다.
- 보드가 변경된 이동 후에만 새 타일(2 또는 4)이 랜덤 빈 칸에 생성됩니다.
- 빈 칸이 없고 이동 가능한 방향이 없으면 게임 오버입니다.

## 실행

```bash
dotnet run
```

```bash

cd test
dotnet run

# Brief 모드 (섹션별 통과 비율만 출력)
cd test
dotnet run --brief
```
